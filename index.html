Selected work

Things I’ve built and shipped.

Three at the bank, three on my own time. All of them are running software, not decks.

  1. CIBC Investor’s Edge

    An agentic product-development platform

    An internal platform where product managers converse with the bank’s AI to go from question to artifact: it spins up lightweight working prototypes, pulls context from the corporate second brain and agent skills files, connects to Figma, and drafts PR-FAQs and BRDs. It also mines years of historical engineering estimates against the BRDs that produced them, so new proposals come back with evidence-based effort estimates.

    Agent harnesses · tool loops · Figma integration · estimate mining

  2. CIBC Investor’s Edge

    A second brain on Open Knowledge Format

    Karpathy’s LLM-wiki pattern made concrete on Google’s Open Knowledge Format: the corporate document corpus indexed into a densely cross-linked graph of markdown notes. Agents retrieve by embedding against the chunked question, loading precise context from the corpus rather than overloading the window with attached files.

    OKF · embeddings · chunked retrieval · agent context

  3. CIBC Investor’s Edge

    ML personalization for direct investing

    Propensity models score every new client — options, ETFs, FHSA/RRSP — into Braze and Contentstack journeys, with closed-loop retraining lifting both model accuracy and conversion over time.

    Propensity modeling · Braze · Contentstack · closed-loop retraining

  4. Independent · live

    FinanceHermes ↗

    A financial-research agent on a hand-built harness: a streaming tool-call loop over live web search, visible reasoning traces, server-side citation enforcement and a two-tier freemium gate. Zero-dependency serverless deploy, demoed live to rooms of investment advisors.

    SSE streaming · tool loop · citation enforcement · serverless

  5. Independent

    Personal OKF knowledge base

    The same LLM-wiki pattern run at home: a cross-linked markdown knowledge graph used as shared context by Claude Code and the other agents I work with day to day.

    OKF · embeddings · agent context

  6. Independent · live

    The Six Cut ↗

    A Next.js discovery product that ranks Toronto’s independent butchers against a proprietary scoring methodology.

    Next.js · Vercel · scoring methodology
